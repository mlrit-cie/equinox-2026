# Equinox Ignition

Build a premium, award-winning, highly interactive event website for:

CIE — Centre for Innovation and Entrepreneurship

MLR Institute of Technology, Hyderabad

EVENT:

EQUINOX

EQUINOX is a 3-day entrepreneurship and innovation event organized by CIE at MLR Institute of Technology.

IMPORTANT:

The attached event blueprint is the source of truth for the event content.

The event includes:

1. SPOTLIGHT

2. CROSSROADS

3. STARTUP EXPO

4. BRAND BATTLES

5. IPL AUCTION

6. HUSTLE MANIA

7. IDEATHON

8. INTERNSHIP DRIVE

9. STARTUP POLY

10. E-CELL MEET

11. PITCH DECK

The website must NOT look like a generic college fest website.

It should look like a professionally art-directed international entrepreneurship summit.

==================================================

DESIGN DIRECTION

==================================================

Use MAXIMALISM as the primary design philosophy.

The visual direction should take inspiration from:

- contemporary maximalist editorial design

- modern event posters

- experimental typography

- street-art-inspired composition

- startup culture

- magazine layouts

- bold graphic design

- collage

- print textures

- oversized typography

- asymmetric grids

The two reference images provided by the user are ONLY visual inspiration.

DO NOT COPY:

- their exact layout

- their typography

- their illustrations

- their assets

- their compositions

- their artwork

- their text

- their logos

Create a completely original visual identity for EQUINOX.
